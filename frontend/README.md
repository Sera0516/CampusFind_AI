# Angular frontend

This folder is the frontend workspace location. Generate the Angular application here with:
`npx @angular/cli new campusfind-frontend --directory . --routing --style css`
Then install Bootstrap:
`npm install bootstrap`
Add `node_modules/bootstrap/dist/css/bootstrap.min.css` to the styles array in angular.json.

The backend API base URL is `http://127.0.0.1:8000`.
